# Clipboard shortcut — 0.4.1

Option + Shift + V replaces Fn + Shift + V. Unset/default settings and previously saved Fn settings resolve to the new chord automatically. Other explicitly selected shortcuts remain available. The settings picker offers the new default, and opening history uses ordinary hotkey registration rather than the Fn event tap. Automatic cross-app paste retains its separate macOS permission requirement.

The packaged-app integration suite checks the default, saved Fn migration, and preservation of other explicit choices.
